1. Какую проблему необходимо устранить в первую очередь? - Отсутствие зафиксированного и согласованного API
2. Какие договорённости нужно зафиксировать? - В течение 1 рабочего дня аналитик совместно с разработчиками фиксирует контракт API, после фиксации изменения в контракт не вносятся без прямого согласования с руководителем проекта
3. Кто отвечает за согласование API? - Руководитель проекта: несёт ответственность за соблюдения договорённости. Системный аналитик: готовит документацию. Frontend и Backend разработчики: подтверждают техническую реализуемость
4. Какие задачи можно выполнять параллельно? - Frontend разрабатывает и отлаживает пользовательский интерфейс на Mock-данных. Backend исправляет ошибки в БД и реализует согласованные API. Тестировщик параллельно пишет тестовую документацию, готовит тестовые данные и проверяет корректность работы Frontend с Mock API
5. Как контролировать дальнейшее выполнение работ? - Назначить промежуточную точку контроля через 3 дня: проверка первой успешной интеграции реального API с Frontend на тестовом стенде
